# Guardians Diagnostic Center Website

A professional, responsive website for Guardians Diagnostic Center built with React, Node.js, and Tailwind CSS.

## 🏥 Project Overview

This website serves as the digital front door for Guardians Diagnostic Center, a modern healthcare facility in Addis Ababa, Ethiopia. The site provides information about diagnostic services, enables appointment booking, and showcases the center's professional medical capabilities.

## 🚀 Tech Stack

### Frontend
- **React 19** - Modern UI framework
- **React Router DOM** - Navigation and routing
- **Tailwind CSS** - Utility-first CSS framework
- **Heroicons** - Beautiful SVG icons
- **Vite** - Fast build tool

### Backend
- **Node.js** - JavaScript runtime
- **Express.js** - Web framework
- **CORS** - Cross-origin resource sharing
- **dotenv** - Environment variable management
- **Nodemon** - Development hot reload
